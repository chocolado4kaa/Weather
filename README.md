# Weather App

## 🇬🇧 English Version

This is a weather application built with **React + Vite**, **SCSS**, **React Redux**, and **Chart.js**.  
It fetches weather data from [WeatherAPI](https://www.weatherapi.com/) and provides a clean, interactive interface.

### Features

- Light and Dark theme toggle 🌗  
- Responsive design for mobile and desktop 📱💻  
- Dynamic weather charts using **Chart.js** 📊  
- Redux for global state management  
- Search weather by city

### Technologies Used

- **React + Vite** – frontend framework and build tool  
- **SCSS** – styling  
- **React Redux** – state management  
- **Chart.js** – interactive weather charts  
- **WeatherAPI** – external API for weather data  

### How to Run

1. Clone the repository:  

   ```bash
   git clone <your-repo-url>
   ```
2. Install dependencies:

   ```bash
   npm install
   ```
3. Start the development server:

   ```bash
   npm run dev
   ```
4. Open your browser at `http://localhost:5173`
